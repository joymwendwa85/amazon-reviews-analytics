# amazon-reviews-analytics
Analysis of Amazon customer reviews
Project Overview

This project analyzes Amazon customer reviews to understand customer feedback, identify trends, and predict customer ratings using data science techniques.

Objectives

NLP: Clean and preprocess review text, identify frequent words, and analyze customer sentiment.

Time Series Analysis: Analyze monthly review counts and average ratings, check stationarity, and forecast future review activity.

Neural Networks: Use TF-IDF and a neural network to classify customer ratings.

Tools and Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, NLTK, Scikit-learn, TensorFlow, and Statsmodels.

Dataset

The dataset contains product IDs, ratings, review text, review summaries, timestamps, sentiment labels, and review length.

Key Results

The project uses word frequency analysis, bigrams, sentiment analysis, time series forecasting, and model evaluation to understand customer feedback. Model performance is assessed using metrics such as accuracy, MAE, and RMSE.

Conclusion

This project helped me apply NLP, time series analysis, and neural networks to real customer review data. The results can help a business understand customer opinions, monitor review trends, and make better decisions.
